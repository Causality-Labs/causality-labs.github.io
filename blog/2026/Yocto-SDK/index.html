What is a Yocto SDK

A Yocto SDK is a toolbox for building software for embedded Linux devices. It’s like a complete workshop that gives you everything you need to write and compile programs for a specific device.

What it contains:

  • Cross-compiler: Tools to compile code for your target hardware (like ARM processors)
  • Libraries and headers: Pre-built software libraries your applications need
  • Debugger: Tools to debug your code on the target device
  • Build tools: Everything needed to compile and package your application

In simple terms: it’s a box of development tools tailored specifically for your target hardware, so you can write and test embedded software on your laptop/desktop and then run it on your actual embedded device.

More details about the Yocto SDK can be found on the official Yocto Documentation page.

Where each variable represents:

  • host_system: Your development system architecture: i686 or x86_64
  • image_type: The image for which the SDK was built: core-image-minimal or core-image-sato
  • arch: The tuned target architecture: aarch64, armv5e, core2-64, i586, mips32r2, mips64, ppc7400, or cortexa8hf-neon
  • release_version: The Yocto Project release number: 5.3.1, 5.3.1+snapshot, etc.

Publishing the SDK to GitHub

Once your SDK is compressed, you can publish it to GitHub as a release so it’s easily accessible across machines.

Creating a GitHub Release

  1. Navigate to your repository on GitHub
  2. Click on Releases in the right sidebar
  3. Click Draft a new release (or Create a new release)
  4. Fill in the release details:
    • Tag version: Enter a version (e.g., v1.0.0 or sdk-6.6-scarthgap)
    • Release title: Give it a descriptive name (e.g., Yocto SDK for i.MX91)
    • Description: Add notes about the SDK, build date, and usage instructions

Uploading the Tarball

  1. In the Attach binaries section, click Attach binaries by dropping them here or selecting them
  2. Select your compressed tarball file: x86_64-imx91frdm-toolchain-6.6-scarthgap.tar.gz
  3. Click Publish release
